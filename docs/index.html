What this project demonstrates

  • OpenAPI-first REST API with versioned routes and idempotency keys
  • Transactional Outbox Pattern for reliable event publishing
  • Layered .NET 10 architecture across 9 projects
  • Repository pattern with raw Npgsql (no ORM)
  • Embedded SQL migrations with automatic tracking
  • Multi-stage Dockerfile with non-root runtime user
  • Docker Compose local dev environment
  • Kubernetes + Helm deployment manifests
  • OAuth2 / OIDC with Auth.Service
  • MCP Server with 4 tools, audit log, and approval gate
  • Python data-quality CLI with pluggable adapters
  • OpenTelemetry → Prometheus → Grafana observability
